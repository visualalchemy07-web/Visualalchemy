# VisualAlchemy website

## Files
- index.html — complete responsive website
- images/ — your three uploaded poster edits

## Preview
Open `index.html` in a browser.

## Publish for free
1. Create a GitHub account.
2. Create a new public repository, for example `visualalchemy`.
3. Upload `index.html` and the `images` folder.
4. In the repository, open Settings → Pages.
5. Select the main branch and the root folder, then save.
6. GitHub will give you a public website address.

You can later connect a custom domain such as visualalchemy.in if you buy one.

## Google Search
Once the site is live, add the site to Google Search Console and request indexing. Google indexing can take time and does not guarantee a particular search ranking.

## Important
Only publish images and artwork you have permission to use. If an edit uses copyrighted movie artwork, keep that in mind when publishing or monetizing the site.
